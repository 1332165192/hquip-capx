# capx 项目介绍

capx 是一款开源的本地抓包、接口分析与自动化测试工具，将代理抓包、请求重放、手机测试入口和 AI 工具接入放在同一工作台中。

仓库：https://github.com/hquip/capx

## 主要用途

- **接口调试**：查看 HTTP/HTTPS 请求与响应，筛选 URL、状态码和内容，重放请求验证接口行为。
- **流量分析**：处理 HTTP/2 与 WebSocket，查看历史、请求正文和响应正文，辅助定位错误与差异。
- **手机 App 测试**：Android 使用 USB/ADB 或 Wi-Fi；iPhone 使用 Wi-Fi 代理。Android 提供截图、点击和基础输入，需要设备授权。
- **AI 协作**：通过 MCP 让 Claude、Cursor 等工具查询流量和执行已授权的测试操作，也可通过 REST API 集成脚本。
- **项目管理**：提供 Web 控制台、桌面端与多实例管理，源代码由 GitHub Actions 编译。

## 示例场景

1. **排查接口500错误**：在 HTTP 历史筛选失败请求，查看参数与响应，发送到重放器验证修改后的请求。
2. **测试自己的 Android App**：连接并授权 ADB，选择手机，配置抓包与测试CA，查看请求并配合截图定位界面操作。
3. **用 AI 分析流量**：通过 MCP 请求 AI“筛选失败接口，比较请求参数与响应差异，整理排查步骤”。主动执行操作需要显式授权。

## 当前支持边界

iOS 点击/输入尚未统一集成；小程序调试需要外部 CDP 提供方，微信本体由使用者自行安装。证书固定与业务层加密需按具体App验证，不能保证所有接口均可解密。
