关于 capx
使用声明与免责声明 · 仅用于本人拥有或取得明确授权的测试环境。

      

        capx 是一个四层一体抓包工具：L7 HTTP/HTTPS/WebSocket（自研 MITM 代理 + 自签 CA）、L3/L4 TCP/UDP（gopacket，-tags pcap）、进程内存扫描（Rust 引擎，-tags memscan_ffi）。
